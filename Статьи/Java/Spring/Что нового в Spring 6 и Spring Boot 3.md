В Spring 6 и Spring Boot 3 появилось ==множество новых функций и улучшений==. Основные моменты включают:

- **Поддержка Java 17:**
    
    Spring 6 использует Java 17 в качестве минимальной версии. 
    
- **[Jakarta EE 9](https://www.google.com/search?sca_esv=dbbcd87e5f308596&cs=0&sxsrf=AE3TifN4EfiQDI7xDb-fUZi4H8g2WqfjfA%3A1754030114994&q=Jakarta+EE+9&sa=X&ved=2ahUKEwjnvPqu_-iOAxVoJBAIHY_LCZ8QxccNegQICxAB&mstk=AUtExfA4M1LXBBC9dUxT-IL5nmveHyZUN_2wwJXvSCRxMzfk6dYohq_mqXYoI04wuKUc7yFzP8ggEt4jNlcExWJ4soc3xrzNknUb0Af7blgCB270ESqJqalX1Sl1kldCukqn28oTLC6FzoZ3JrbA-2el6NLv5uE_giK3oxN0U2SRXBxNiLgHWH-dlmlUZcsq9JyUrW7c03hZCNWhwiZNKlscDTzl6jaj8g37J8nm7K-pFut8xM7MwbZqtN3hPlv8YdHnlQbP6iuiMTnrzWyYChueItlM&csui=3):**
    
    Обеспечивается совместимость с Jakarta EE 9 и более поздними версиями. 
    
- **Улучшенная наблюдаемость (Observability):**
    
    Внедрена Spring Observability, основанная на Micrometer и Micrometer Tracing, для эффективного логирования метрик и реализации трассировки. 
    
- **Реактивное программирование:**
    
    Улучшена поддержка реактивных API и фреймворков, таких как Project Reactor и Spring WebFlux, для создания высокопроизводительных, масштабируемых приложений. 
    
- **Обновление зависимостей:**
    
    Улучшена совместимость с новыми версиями зависимостей и библиотек. 
    
- **Модульность:**
    
    Spring 6 продолжает развивать модульность, начатую в Spring 3, позволяя использовать отдельные модули в виде отдельных JAR-файлов. 
    
- **Упрощенный API для HTTP-клиента:**
    
    Представлен новый, более удобный API для работы с HTTP-клиентом, построенный на основе клиента HttpClient из JDK 11+. 
    
- **Поддержка GraalVM Native Image:**
    
    Spring 6 поддерживает создание нативных образов GraalVM, что позволяет значительно сократить время запуска и потребление ресурсов приложения. 
    
- **Улучшенная интеграция с облачными платформами:**
    
    Более тесная интеграция с облачными сервисами и инфраструктурами, такими как AWS, Azure и GCP. 
    

В целом, Spring 6 направлен на поддержку современных технологий, повышение производительности и улучшение наблюдаемости приложений, а также на упрощение разработки современных облачных приложений.
